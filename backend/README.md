# Backend - CyberGuard System

Pendiente de implementación.

Este módulo será el Producer (API REST) que:
- Recibe alertas de seguridad desde el frontend
- Valida y publica eventos a RabbitMQ
- Maneja autenticación con JWT (usuario hardcodeado)

Stack: Node.js + Express + TypeScript + RabbitMQ (amqplib)
